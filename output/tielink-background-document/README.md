# TieLink 主 Agent：后台文档任务体验版

2026-11-25。本目录 APK 为本地 Debug 构建，使用应用中已配置的模型。本轮没有使用用户 API Key 发起实际生成。

## 建议体验路径

1. 安装 `TieLink-background-document-debug.apk`，检查应用原有的模型设置。
2. 在主 Agent 对话里输入：**帮我把“面试复盘小助手”这个灵感整理成一页方案，包含目标用户、核心流程、最小功能和待验证问题，我先去忙。**
3. 收到“文档任务已保存”卡片后切换到其他应用。允许通知时，可从通知查看实际步骤、生成中的片段或已经保存的草稿节选。
4. 点击通知打开该任务。文档完成后可查看草稿、预览 HTML，或将 Markdown / HTML 导出到自己选择的位置。
5. 点击“回原对话”，输入 **再简短一点，突出验证方法**。这会保留原稿并建立关联修订任务。
6. 从输入区的团队入口创建“灵感整理团队”，填写用途和工作要求，选择是否默认生成 HTML。保存配置后不会启动任务；选用团队，再发送新的文档委托即可使用。

## 已实现的细节

- 聊天、持久队列、独立后台服务和任务详情相连。背景任务执行时，主聊天仍可使用。
- 每次只实际执行一项后台文档任务，其他任务排队。
- 暂停、继续、取消；中途补充要求后旧执行失效，不覆盖新要求。
- 生成中的片段明确标为未完成，只有约定产物保存齐全才完成。
- 自定义团队的创建、编辑、删除、选用；任务保存当时的配置，之后编辑或删除团队不改变该任务。
- 本次明确的 HTML 交付要求可覆盖团队默认值；不会修改可复用团队。
- 没有通知权限时仍可从聊天顶部任务入口查看。

## 当前范围与验证边界

本版提供文档草稿与可选 HTML。简历、PDF 仍使用原有工具入口。自定义团队目前是主 Agent 使用的可复用工作要求和工具选择；多个角色独立执行、任意工具编排和按名称自动匹配团队还未实现。

普通切后台与进程终止不同：发生系统回收或进程终止后，下次进入会保留任务并核验为暂停，用户点击继续。关机期间执行不在需求范围。断网或模型配置失败后需修复并手动继续。

APK 构建、JVM 测试、仪器测试编译与 Agent 模块 Lint 已纳入核验；最终统计和 APK SHA256 见 `verification.json`。当前没有连接 Android 设备或可用 AVD，未实际验收切后台、锁屏、系统通知、真实模型、系统回收和系统文件导出，不将编译成功等同于设备验收通过。

更多代码与验证记录见 `docs/AGENT_BACKGROUND_IMPLEMENTATION.md`。
