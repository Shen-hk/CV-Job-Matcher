页面转场与微交互规范

对应 Compose 侧 motionForwardEnter/Exit、motionBackEnter/Exit 的升级方案。全部动效仅作用于 transform / opacity，保证 60fps 与低功耗。

页面转场 · Forward / Back

进入：translateX(18%) + fade，420ms ease-out-quint
返回：反向位移动画，320ms
沉浸页（面试）：fade + scale(0.96→1)，无横向位移

组件级微交互

卡片按压 — scale 0.97，80ms 按下 / 280ms 弹回
按钮成功态 — 打勾描边 400ms + 轻微 scale 弹跳
评分环 — dashoffset 生长 1.2s + 数字滚动
列表入场 — 逐项 stagger 40ms fadeUp
AI 气泡 — 流式打字 + 光标闪烁
状态切换 — 时间线节点填充波纹扩散

无障碍与性能红线

✓ 正文对比度 ≥ 4.5:1，大字号与图标 ≥ 3:1
✓ 动效状态不以颜色为唯一传达（附图标/文案）
✓ 尊重系统「减弱动态效果」：转场退化为淡入淡出
✓ 仅动画 transform/opacity，禁用 layout 属性动画
✓ 列表长页入场 stagger 上限 8 项，防动画过载
