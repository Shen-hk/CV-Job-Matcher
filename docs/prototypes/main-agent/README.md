# TieLink 主 Agent 交互原型

2026-11-25。独立 HTML/CSS/JavaScript，无需安装依赖或配置 API Key。直接打开 `index.html`，或在本目录运行 `python -m http.server 8817 --bind 127.0.0.1` 后访问本机端口。

在仓库运行 `node docs/prototypes/main-agent/build.mjs`，可将样式和脚本合并为 `output/tielink-agent-prototype/TieLink-Agent-Prototype.html`，便于作为单文件打开和传递。

首页是主 Agent 聊天，团队与工具放在侧栏。桌面显示任务面板；手机宽度使用侧栏抽屉和对话内任务卡。

## 推荐体验路线

1. 点击首页“把简历，打磨得更好”，使用内置示例资料接下任务。
2. 点击顶部“推进一步”快速查看阶段变化；也可以等待每约 8 秒自动推进。
3. 点击“切到后台”，再下拉通知；通知同时展示当前动作与已保存的阶段成果。
4. 点击通知“查看成果”，打开阶段草稿；任务仍继续执行。
5. 完成后在原会话继续说“再突出项目经历”，生成关联的新版本。
6. 从“我的团队”编辑角色、工具与偏好；保存配置不启动任务，运行绑定原有团队版本。

## 可操作的分支

- 顶部切换“需要补充资料”或“PDF 导出失败”，再创建新任务。
- 缺资料时补充内置示例或本地文件引用；失败后只重试 PDF 步骤。
- 暂停、继续、取消、模拟断网和恢复；多任务全局串行排队，等待补充不占执行位置。
- 运行期间聊天、补充要求、开启其他会话；查看任务历史及未读结果。
- 直接查看示例 PDF，不创建团队或运行任务。
- 查看文档、编辑草稿并保存新版本、HTML 预览、下载真实 TXT/HTML 文件。
- 原型通知开关关闭后仍可从应用内找回结果。
- 对话、团队、执行位置与草稿保存在本浏览器；从工作空间设置可清空本原型记录。

## 模拟边界

这是用于评审产品与交互的原型。任务采用内置示例内容和定时状态变化，不调用模型、上传文件或启动真正的 Android 后台服务。自定义输入用于记录需求和演示状态，并不代表真实 AI 理解或生成。文件选择只记录文件名，不进行真实 PDF/DOCX 解析。

通知是页面内的系统通知示意，不申请浏览器通知权限。浏览器后台计时可能被系统节流；不能用该原型证明 Android 的后台可靠性。

PDF 卡片与阅读页展示示例内容，不自动生成 PDF 二进制文件。可通过“打印 / 另存 PDF”调用浏览器打印；文档和 HTML 下载会生成真实文件。原始示例、修改版本和历史产物可分别查看。

原型仅在用户主动启动任务后推进，不会因打开首页或保存团队配置自动运行。
