## 验证边界

上述检查针对浏览器原型。没有调用模型，没有实测 Android 服务、系统通知、锁屏或进程回收。PDF 为阅读界面示意；浏览器打印入口已提供，系统打印对话框未在自动流程中提交。原型验证不替代产品后台执行的设备验收。
