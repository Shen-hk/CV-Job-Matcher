03

转场与微交互规范

对应 Compose 侧 motionForwardEnter/Exit、motionBackEnter/Exit 升级参数。全部动效仅作用于 transform / opacity，保证 60fps。

页面转场 · Forward / Back

进入：translateX(18%) + fade · 420ms ease-out-quint
返回：反向位移 · 320ms
沉浸页（面试）：fade + scale(.96→1)，无横向位移

组件级微交互

卡片按压 — scale 0.97 · 80ms 按下 / 280ms 弹回
开关切换 — 滑块 160ms + 轨道颜色 200ms 交叉
评分环 — dashoffset 生长 1.2s + 数字滚动
消息气泡 — 逐条浮入 300ms · 流式打字光标
进度节点 — 当前节点波纹扩散 2s 循环
列表入场 — stagger 40ms · 上限 8 项

无障碍与性能红线

✓ 正文对比度 ≥ 4.5:1（#17181D on #F5F6FA = 15.4:1）
✓ 状态不只靠颜色传达：缺口含「缺失/加分」文字标签
✓ 尊重系统「减弱动态效果」：转场退化为 200ms 淡入
✓ 仅动画 transform / opacity，禁用 layout 属性动画
✓ 触控目标 ≥ 44×44pt（按钮 44-46px 高）
TieLink · Aurora UI v2 高保真概念稿 · 覆盖 NavGraph 全部 14 个路由界面
确认方向后可逐屏输出 Compose 实现文档（Theme Token → 组件 → 动效常量）
